# 环卫小卫士 (Sanitation Hero)

一个用键盘方向键玩的环卫小游戏。你是一名环卫工人，捡地上的垃圾、装进背包、送到垃圾桶换分数；
灰色小人会到处乱逛并且随手丢垃圾，**碰到他们就能把他们感化成同伴**，一起帮你扫街。

## 怎么运行

直接双击 `index.html`（推荐 Chrome / Edge，无需安装任何东西，也不用起服务器）。
或者克隆下来再打开：

```
git clone https://github.com/guranguranguran/candy-game-snake.git
cd candy-game-snake
start "" index.html        # Windows
open index.html           # macOS
xdg-open index.html       # Linux
```

## 操作

鼠标为主，键盘作为备用：

| 操作 | 作用 |
| --- | --- |
| 移动鼠标 | 鼠标模式：鼠标移到哪，小人就走到哪（有速度上限，不是瞬移） |
| 点操作方式按钮 | 「鼠标控制 / 键盘控制」两个按钮，切换用鼠标还是键盘玩 |
| 点难度按钮 | 菜单/暂停界面上的「休闲 / 标准 / 困难」，点一下 = 换难度并开局 |
| 点一下鼠标 | 开始游戏 / 通关或失败后重开 / 暂停时继续 |
| M | 随时切换鼠标 / 键盘操作（菜单、暂停、游戏中都能按） |
| ↑ ↓ ← → 或 W A S D | 键盘模式下的移动；鼠标模式下按下方向键也以键盘为准 |
| 1 / 2 / 3 | 在菜单或暂停界面直接选难度开局 |
| 空格 / 回车 | 开始游戏 / 通关失败后重开 |
| P | 暂停 / 继续 |
| R | 重开一局（暂停、通关、失败界面下可用） |

触摸屏也可以直接按住拖动，小人跟着手指走。

## 规则

1. 小人踩到地上的垃圾，就自动捡进背包，**背包最多装 5 件**。
2. 背包满了（或想中途交）走到地图中间的垃圾桶旁，垃圾自动倒进桶里，**每件 1 分**，
   装满 5 件送一趟正好 5 分。
3. 地图上会随机冒出新的垃圾；灰色小人也会随机停下丢垃圾。
4. 灰色小人看到你会跑，追上去碰到他就**感化成同伴**（变成绿色）。
   同伴会自动找最近没人捡的垃圾，装够 5 件自己送去垃圾桶，分数同样算你的。
5. **通关**：分数达到本难度的目标分（休闲 120 / 标准 150 / 困难 200）。
   **失败**：地图上的垃圾累积到本难度的上限（休闲 50 / 标准 45 / 困难 40 件，脏乱度爆表）。

小提示：单靠自己捡是追不上垃圾产生速度的，先把灰色小人感化掉才是正解。
难度越高，需要感化的人越多、垃圾冒得越快，所以「先追人」这件事就越关键。

## 操作方式（鼠标 / 键盘）

三处都能切，效果一样：

- 菜单和暂停界面底部有两个按钮：**鼠标控制** / **键盘控制**
- HUD 右上角有一枚常驻胶囊（写着「操作 鼠标」或「操作 键盘」），**游戏中也能点着切**，不用先暂停
- 键盘按 **M** 随时切

区别：

| 模式 | 表现 |
| --- | --- |
| 鼠标控制（默认） | 小人自动朝鼠标位置走过去；鼠标停住小人就停住。方向键仍然可用，按下时以键盘为准 |
| 键盘控制 | 小人只认 ↑↓←→ / WASD，鼠标怎么动都不影响小人（鼠标仍可用来点按钮、开始游戏） |

切换操作方式**不会重开当前局**，可以打着打着换手感。

## 难度

菜单界面和暂停界面上有三个难度按钮，点一下 = 换难度并直接开局（游戏中点按钮不会打断当前局）。

| 难度 | 开局灰人 | 灰人丢垃圾 | 地图冒垃圾 | 追人难度 | 目标分 | 失败线 | 后期加速 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 休闲 | 3 | 每 3.5~7 秒 | 每 3.5~7 秒 | 慢（会小跑） | 120 | 50 件 | 到 1.5 倍 |
| 标准 | 6 | 每 3.0~6 秒 | 每 2.0~4 秒 | 中 | 150 | 45 件 | 到 1.7 倍 |
| 困难 | 9 | 每 4.5~8 秒 | 每 1.6~3.2 秒 | 快（很能跑） | 200 | 40 件 | 到 2.0 倍 |

「后期加速」指游戏进行中丢垃圾/冒垃圾的间隔会越来越短，最多缩到上面这个倍数，
所以拖得越久越难，靠感化同伴滚雪球才是唯一出路。

## 改数值

难度全部集中在 `js/game.js` 顶部的 `DIFFS` 表里，改数字就行：

| 字段 | 含义 |
| --- | --- |
| `startNpc` / `maxNpc` | 开局灰色小人数 / 场上最多几个 |
| `drop` | 灰色小人每隔多少秒丢一次垃圾 `[最小, 最大]` |
| `spawn` | 地图每隔多少秒自动冒一件垃圾 `[最小, 最大]` |
| `newNpc` | 每隔多少秒新冒出一个灰色小人 |
| `npcSpeed` / `fleeSpeed` | 灰人游荡 / 逃跑速度（逃跑速度必须低于 240，否则追不上） |
| `greenSpeed` | 同伴速度 |
| `target` / `maxDirt` | 通关分数 / 失败线 |
| `ramp` | 后期加速上限（0 = 不加速） |

其他全局参数：`CAP` 背包容量 5、`PLAYER_SPEED` 小人速度 240、
`MOUSE_SPEED_MULT` 鼠标跟随速度倍率、`NPC_FLEE` 灰人是否会逃跑、`START_GARBAGE` 开局垃圾数 8。

## 自动化测试

核心规则 + 操作方式 + 鼠标控制 + 难度 + 渲染健康度共 46 条用例，可在 Node 无头和真实浏览器里各跑一遍：

- 逻辑（T1~T11）：方向键移动与边界夹取、踩到捡起、背包上限、满了捡不起来、走到垃圾桶得分、
  感化灰色小人、同伴自动干活、通关判定、失败判定、暂停
- 鼠标（T12~T16）：指哪走哪、走到就停不抖、键盘优先于鼠标、坐标换算（画布缩放后仍准确）、点击开始
- 难度（T20~T24）：三档开局灰人数 3/6/9、目标分与失败线随难度变化、
  标准难度垃圾产生确实快于休闲、按钮齐全、点按钮切难度开局、游戏中点按钮不打断、暂停时点按钮换难度重开
- 操作方式（T25~T29）：默认鼠标、鼠标拉着走、M 键切换、键盘模式下鼠标完全不影响小人、
  键盘模式方向键可用、点 HUD 胶囊切换、菜单两个按钮切换且不会误开局
- 渲染（T17~T19）：主循环会持续自我排程（不会卡死在第一帧）、绘制过程零报错、
  画布真的画出了内容（对画布取样，颜色种类 > 20）

## 调试接口

浏览器控制台里有 `SG` 对象，方便调参和自动化测试：

```js
SG.reset()          // 重开
SG.step(60)         // 手动推进 60 帧（不依赖 requestAnimationFrame，适合无头测试）
SG.state()          // 'menu' | 'play' | 'pause' | 'win' | 'lose'
SG.score()          // 当前分数
SG.dirt()           // 地图上的垃圾数
SG.bag()            // 背包里的垃圾数
SG.npcs()           // [{ kind: 'gray' | 'green', x, y }]
SG.player()         // 小人对象，可读写 x / y 做传送测试
SG.garbageList()    // [{ id, x, y }]
SG.mouse()          // { x, y, active } 鼠标目标位置（画布逻辑坐标）
SG.setMouse(x, y)   // 直接设定鼠标目标（自动化测试用）
SG.clearMouse()     // 关掉鼠标跟随（测试里避免小人被鼠标拽走）
SG.frames()         // 已渲染帧数
SG.errors()         // 渲染报错次数（正常应为 0）
SG.control()        // 'mouse' | 'keyboard' 当前操作方式
SG.setControl(id)   // 切换操作方式
SG.controlButtons() // 菜单里两个操作方式按钮的坐标
SG.controlPill()    // HUD 上那枚操作胶囊的坐标
SG.difficulty()     // 'easy' | 'normal' | 'hard'
SG.setDifficulty(id)
SG.diffButtons()    // 三个难度按钮的坐标
SG.target() / SG.maxDirt() / SG.startNpc()   // 当前难度的目标分 / 失败线 / 开局灰人数
```
